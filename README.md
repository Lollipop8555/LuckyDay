# 幸运签

这是一个抽签的网页项目，可以在网页上进行抽签，抽签结果会显示在网页上，然后提供签的分析结果。


## 功能

- 抽签的结果会保存到浏览器本地，有效时间为自然天，当天再次打开网页，会显示历史结果，但是允许再次抽签。
- 抽签基于用户当前的 IP 信息以及时间信息等来加权计算，将计算结果转换并且映射到内置的抽签数据。
- 内置两套抽签数据，一套为：浅草寺观音一百签(data/data.zh.json)，另一套为：诸葛神算三百八十四签(chims.chs.json)。
- 页面上支持两个抽签系统分别抽签，并且记录的数据也是相互独立的。
- 初始化状态下，页面只有下方的“抽签”和切换抽签系统的 Tab 按钮。
- 点击“抽签”后，屏幕中央出现长条形卡片动画，卡片上方显示评级，如上上签；卡片下方展示展示签的谏言，分两列垂直排列。下方提供“解签”按钮；每一根抽出来的签从左往右排列，最新的在右边，整体居中。
- 点击解签，展示解析内容，展示为对话框。
- 抽签之后，屏幕上始终展示抽到的签，下方抽签按钮变为“重抽”
- 抽到“凶”，“下下签”，”中下签“的时候，弹出提示”哎呀，锦鲤为你换一个签“，然后自动重新抽取，直到不是“凶”，“下下签”，”中下签“的时候，才结束。

## 技术栈

- 前端：Vue 3 + Vite（H5 移动风格，窄屏/宽屏自适应）
- 后端：Node.js (Express)
- 部署：Docker `node:20` 容器

> 说明：项目为前后端一体。前端经 `npm run build` 构建为 `dist/`，由 Express 在 `3000` 端口统一托管并提供 API。

## Docker 部署

Docker Compose 参考配置（仅作部署参考，**不属于本项目**，项目会被整体部署到该配置中的 `app` 目录下）：

```yaml
version: '3.8'

services:
  LuckyDay:
    image: node:20
    container_name: LuckyDay
    restart: always
    ports:
      - "3902:3000"
    volumes:
      - ./app:/app
    working_dir: /app
    command: sh -c "npm install && npm run build && npm start"
```
